Exposed devices

    
Exposing entities controls what PETEY can see and control. Home Assistant 2026.9 asks about Control Home Assistant while adding the Model Context Protocol Server integration; it does not provide a later Options screen. The add-on connects only to the official /api/mcp/assist endpoint.

    
Home Assistant may use a technical domain that differs from the real device type. For example, automatic litter boxes commonly use the vacuum domain. PETEY uses the friendly entity name and should still call them litter boxes. Enabling a device integration does not expose every related sensor; expose each sensor you want Assist to share.
